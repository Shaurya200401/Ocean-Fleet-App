# Ocean Fleet App

## Ocean Fleet App - Object-Oriented Programming Vessel Identifier

A Java project that stores vessel information and gradually extends to retrieving vessel details and identifying high-performance vessels.

## UC1: Create Vessel Model
Defines a basic data model to represent a vessel and its performance attributes.

## UC2: Store Vessel Records Using List
Stores multiple vessel records efficiently in memory.

## UC3: Retrieve Vessel by Vessel ID
Fetches a specific vessel’s details using its unique ID.

## UC4: Identify High-Performance Vessels
Finds vessels with the highest average speed.

## UC5: Integrate User Interaction (Console App)
Allows user-driven execution through console input.

## UC6: Refactor Using OOPS Principles
Improves maintainability and scalability using OOPS best practices.

## How to Run
Compile using javac OceanFleetApp.java and run using java OceanFleetApp.
